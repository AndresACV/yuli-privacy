## Immutable release snapshots

Yuli stores independent Privacy Notice and Terms version numbers. The current baseline is version 1:

- [Privacy Notice v1](https://andresacv.github.io/yuli-privacy/versions/v1/privacy-policy.html)
- [Aviso de Privacidad v1](https://andresacv.github.io/yuli-privacy/versions/v1/privacy-policy-es.html)
- [Terms of Service v1](https://andresacv.github.io/yuli-privacy/versions/v1/terms-of-service.html)
- [Términos de Servicio v1](https://andresacv.github.io/yuli-privacy/versions/v1/terms-of-service-es.html)

Released files under `versions/` must never be modified. See [VERSIONING.md](VERSIONING.md) for the coordinated material-change procedure.
